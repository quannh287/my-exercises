# Glossary — dùng CHÍNH XÁC các từ này, không tự chế biến thể

## Dụng cụ
barbell = thanh đòn · dumbbell = tạ đơn · kettlebell = tạ ấm · cable = cáp
EZ barbell = thanh EZ · olympic barbell = thanh Olympic · trap bar = thanh trap
smith machine = máy Smith · leverage machine = máy đòn bẩy · sled machine = máy đẩy xe
resistance band = dây kháng lực · band = dây thun · rope = dây thừng
body weight = tay không · weighted = có thêm tạ · assisted = có hỗ trợ
stability ball = bóng thăng bằng · medicine ball = bóng tạ · bosu ball = bosu ball
wheel roller = bánh xe lăn · roller = con lăn · tire = lốp xe · hammer = búa tạ
stationary bike = xe đạp tại chỗ · elliptical machine = máy elliptical
stepmill machine = máy leo bậc · skierg machine = máy SkiErg
upper body ergometer = máy tay quay

## Bộ phận / cơ
chest = ngực · back = lưng · shoulders = vai · waist = core/bụng
upper arms = tay trên · lower arms = cẳng tay · upper legs = đùi · lower legs = bắp chân
abs = cơ bụng · obliques = cơ liên sườn · lats = cơ xô · traps = cơ thang
delts = cơ vai · pecs/pectorals = cơ ngực · biceps = cơ tay trước · triceps = cơ tay sau
quads = cơ đùi trước · hamstrings = cơ đùi sau · glutes = cơ mông · calves = bắp chân
forearms = cẳng tay · core = core · lower back = thắt lưng · hip flexors = cơ gấp hông
adductors = cơ khép · abductors = cơ dạng · rotator cuff = chóp xoay vai

## Động tác
press = đẩy · bench press = đẩy ngực · overhead press = đẩy vai qua đầu
push-up = chống đẩy · pull-up = hít xà · chin-up = hít xà tay ngửa
row = kéo · deadlift = deadlift · squat = squat · lunge = lunge · plank = plank
curl = cuốn tay · extension = duỗi · flexion = gập · fly/flyes = ép ngực
raise = nâng · lateral raise = nâng tạ ngang vai · front raise = nâng tạ trước mặt
pulldown = kéo xuống · pushdown = đẩy xuống · shrug = nhún vai · dip = xoạc xà
crunch = gập bụng · sit-up = gập bụng toàn thân · leg raise = nâng chân
thrust = đẩy hông · hip thrust = đẩy hông · calf raise = nhón bắp chân
twist = xoay người · stretch = giãn cơ · hold = giữ · pulse = nhấp

## Tư thế / biến thể
seated = ngồi · standing = đứng · lying = nằm · incline = ghế dốc lên
decline = ghế dốc xuống · flat = ghế phẳng · bent-over = gập người
kneeling = quỳ · one arm / single arm = một tay · alternate = luân phiên
close grip = nắm hẹp · wide grip = nắm rộng · reverse grip = nắm ngược
neutral grip = nắm trung tính · underhand = tay ngửa · overhand = tay sấp
